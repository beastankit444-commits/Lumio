# Lumio v1.0

## First Website Release

Lumio v1.0 turns the original adaptive quiz engine into a small Flask website.

### Included

- Subject and quiz-length selection
- One-question-at-a-time quiz interface
- Rule-based adaptive difficulty from 1 to 3
- No repeated questions during a quiz
- Immediate answer feedback after submission
- Results dashboard with topic performance and weakest topic
- Responsive HTML, CSS, and Vanilla JavaScript frontend

This release does not claim machine-learning or other AI functionality.
